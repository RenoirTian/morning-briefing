# Morning Briefing

Auto-generated daily briefing: A-share & US indices, top movers, new stocks, finance & tech news.

**Live:** `https://YOUR_USERNAME.github.io/morning-briefing/`

## Features

- A-Share indices (SSE, SZSE, ChiNext, STAR 50, CSI 300)
- US indices (DJIA, NASDAQ, S&P 500)
- Top gainers & losers
- New stocks / IPO
- Finance headlines with source links
- Tech news with source links
- Dark theme, responsive HTML

## Auto-Update

GitHub Actions runs every weekday at 08:00 HKT, fetches latest data from public APIs, and deploys the static HTML to GitHub Pages.

## Local Run

```
python briefing.py
```
